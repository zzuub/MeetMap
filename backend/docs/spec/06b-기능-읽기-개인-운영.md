서식은 [6.0](06a-기능-읽기-공개.md) 을 따른다. 이 파일의 조회는 전부 **인증이 필요하고**, 범위는 토큰에서 꺼낸다 (5.5) — 경로의 `me` 는 인증 주체이고, 주최사 표면의 범위는 담당 연결의 주최사다.

### 6.5 USER

#### R-20 세션 · R-21 내 프로필 · R-22 찜 id

| 칸 | 내용 |
| --- | --- |
| R-20 결과 | 계정 id · 역할 · 멤버십 상태 · `isNewUser` · 닉네임. `isNewUser` 는 약관 이력에서 파생한다 (4.11) |
| R-21 결과 | 닉네임 · 출생연도 · 성별 · 선호 지역 · 프로필 사진 · 완성도(7장) |
| R-21 예외 | **닉네임·성별이 없으면 `404`** — 선호 지역만 저장돼 있어도 그렇다. 반쪽 프로필을 내리면 가격·자격 판정이 근거 없이 열린다 ([`endpoints.ts`][ep] · [decisions 4.44][dec]) |
| R-22 결과 | 찜한 회차의 **id 만**. 마감·지난 회차도 들어 있다. 회차 목록 응답의 `isLiked` 와 같은 기준이어야 한다 ([decisions 4.59·4.62][dec]) |

#### R-23 알림함 · R-24 알림 설정

| 칸 | 내용 |
| --- | --- |
| R-23 입력 | 안읽음만 볼지, 커서 |
| R-23 처리 | 최신순, 커서 페이지 (제안 — FE 10.2 는 페이지 방식을 정하지 않았다). 전체 수·안읽음 수를 함께 싣는다 — 필터 칩이 `전체 N`·`안읽음 N` 이다 ([FE 10.2][fe08]) |
| R-24 처리 | 행이 없으면 기본값을 돌려준다 — 관심지역 신규 ON · 후기 작성 요청 ON · 추천 소식 OFF · 방해 금지 `23_08` ([FE 10.3][fe08]) |

#### R-25 내가 쓴 후기

| 칸 | 내용 |
| --- | --- |
| 입력 | 분류(`전체`·`분위기`·`진행`·`장소`), 커서 |
| 처리 | 내 후기를 최신순으로. **평점 요약·인기 태그는 싣지 않는다** — 내 후기 평균은 의미 없는 값이다 ([FE 10.4][fe08]). `보류`·`삭제` 된 내 후기를 보여줄지는 O-09 와 함께 정한다 |

#### R-26 마이 요약

| 칸 | 내용 |
| --- | --- |
| 처리 | 찜 수 · 내 후기 수 · 안읽음 알림 수 · **작성할 후기**(참여 인증했는데 아직 안 쓴 회차와 참여일 — O-01) · 프로필 완성도. 한 번에 내린다 (제안) — 마이페이지 카운터 3종과 홈 헤더의 안읽음 점이 같은 값을 쓴다 ([FE 10.1][fe08] · [FE 5-3][fe04]) |
| 미결 | 카운터 셋 중 `신청 이력` 은 서버가 셀 수 없다 — MeetMap 은 신청을 모른다(D-02). 무엇을 보여줄지 O-67 |

#### R-27 역지오코딩

| 칸 | 내용 |
| --- | --- |
| 입력 | 좌표 — **요청 본문**으로 받는다. 조회인데 `POST` 인 것이 요점이다 |
| 처리 | 1. 좌표를 표시용 지명과 지역 마스터 값으로 바꾼다 (외부 지오코딩 — 9장)<br>2. **좌표를 저장하지도, 로그에 남기지도 않는다** — 요청 로그·오류 로그·APM 에 본문을 싣지 않는다 |
| 결과 | 표시용 지명, 지역 마스터 값 또는 `null`. 마스터 밖 문자열을 내리면 프론트의 `/explore?area=` 가 조용한 0건이 된다 |
| 근거 | [`endpoints.ts`][ep] `geo.reverse` · [decisions 4.53·4.54][dec] · [FE 4.1][fe03] 고정 문구 |

### 6.6 주최사 (파트너)

**통계에 쓰는 값은 셋뿐이다 — 조회 · 찜 · 신청 URL 이동** (D-02). 지원·선발 수치는 싣지 않는다. 조회의 정의는 O-05, 기간·증감의 기준은 O-68.

#### R-30 대시보드 · R-31 회차별 통계

| 칸 | 내용 |
| --- | --- |
| R-30 결과 | 개정본 상태별 수(`검수 대기`·`승인`·`반려`) · 기간 합계(조회·찜·신청 URL 이동·이동률)와 증감 · 최근 회차 목록(상태 필터, 회차마다 조회·찜) ([목업 Provider][mk-prov] 대시보드) |
| R-31 결과 | 그 회차의 조회·찜·이동·이동률, 일별 조회, 유입 단계(조회 → 찜 → 신청 URL 이동) ([목업 ProviderManage][mk-provm] 통계) |
| 예외 | 남의 주최사 회차 `404` (5.5) |

#### R-32 ~ R-36

| ID | 처리 · 결과 | 근거 |
| --- | --- | --- |
| R-32 | 자기 주최사 회차 목록과 한 건의 내용. **검수 대기 개정본이 있으면 그 내용을**, 없으면 공개본을 돌려준다 (제안) — 수정 화면이 방금 낸 요청을 다시 보여줘야 한다. 반려된 개정본은 사유와 함께 | [목업 ProviderManage][mk-provm] · 4.6 |
| R-33 | 동의 항목 · 이미지 사용 범위 · 계약 기간(남은 날) · 정산 방식 텍스트 · 담당자·사업자 정보. **읽기 전용** | [목업 ProviderManage][mk-provm] 계약 · D-03·D-04 |
| R-34 | 담당자명 · 연락처 · 계정 이메일 · 알림 수신 설정 4종 중 셋(검수 결과 · 주간 성과 리포트 · 계약 만료 안내 — `지원서 접수 알림`은 뺀다, D-02) · 연동한 소셜 | [목업 ProviderManage][mk-provm] 계정 · D-01 |
| R-35 | 가입 신청의 상태와, 반려됐으면 사유 (O-16·O-28) | [dev-plan 3.5][plan] `/provider/pending` |
| R-36 | 자기 주최사 모든 회차의 후기 — 답글 여부·신고 여부를 싣는다. 공개 목록(R-10)과 달리 `보류` 후기를 볼지는 O-09 | D-05 · [dev-plan P7-4][plan] |

### 6.7 운영

#### R-40 운영 대시보드

| 칸 | 내용 |
| --- | --- |
| 결과 | 기간 합계(조회 · **신청 URL 이동률** — 목업의 `신청 전환율`, O-45) · 등록 회차 수와 주최사 수 · 검수 대기 수 · 시간대별 **신청 URL 이동** 분포 · 조회수 상위 회차 5개와 각 이동률 ([목업 Admin][mk-admin]) |
| 규칙 | 시간대 구간은 서버의 4구간(경계 12·17·21시)이다 — 목업 라벨 `17–22시`·`22시 이후`는 쓰지 않는다 (D-06 · O-40) |

#### R-41 검수 목록 · 상세

| 칸 | 내용 |
| --- | --- |
| 목록 | 상태 필터(`검수 대기`·`승인`·`반려`·전체), 검수 대기 수, 접수 시각 · 제목 · 주최사 · 일시 · 가격 |
| 상세 | 등록 이미지 · 그 주최사의 **현재 유효한** 동의·계약 범위와 기간 · 등록 문구 · 확인 항목 4개 · 반려 사유 목록 ([목업 Admin][mk-admin]). **수정 요청이면 공개본과 달라진 필드를 함께 싣는다** (제안) — 무엇을 승인하는지 보여야 한다 |

#### R-42 ~ R-46

| ID | 처리 · 결과 | 근거 |
| --- | --- | --- |
| R-42 | 상태 필터(`승인 대기`·`승인`·`반려`·전체), 승인 대기 수, 상호 · 사업자등록번호 · 담당자 · 연락처 · 이메일 · 운영 지역 · 신청 시각. **같은 이름·사업자등록번호의 기존 주최사 후보**를 함께 싣는다 (제안) — 승인 때 기존 프로필과 연결해야 한다 (D-01) | [목업 AdminManage][mk-adminm] |
| R-43 | 필터(전체 · USER · PROVIDER · 정지), 이름(닉네임 또는 상호) · 이메일 · 구분 · 상태, 펼치면 가입일 · 최근 접속 · 신고 누적(그 회원 후기에 달린 신고 수) | [목업 AdminManage][mk-adminm] · 4.14 |
| R-44 | 목록: 필터(`신고접수`·`보류`·`삭제`·전체), 신고 수 · 최근 신고 시각 · 작성자 · 회차 · 별점 · 본문 · 대표 사유. 상세: 접수번호 · 신고 내역 전부 · 처리 상태 · **처리 메모(운영자에게만)** | [목업 AdminManage][mk-adminm] · 4.14 |
