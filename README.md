# MeetMap

## 프로젝트 소개

**MeetMap**은 2030 사용자를 위한 **로테이션 소개팅 통합 탐색 플랫폼**입니다.

지금 로테이션 소개팅은 인스타그램 계정 단위로 흩어져 있습니다. 주최사마다 자기 계정에서 일정을 공지하고, 신청은 프로필 링크(링크트리·자체 랜딩 등)로 따로 받습니다. 사용자는 어떤 소개팅이 열리는지 알려면 계정을 하나씩 찾아 팔로우해야 하고, 조건(연령대·지역·성비·가격)을 나란히 비교할 방법이 없습니다.

MeetMap은 **이 흩어진 소개팅을 한곳에 모아 비교·탐색하게 해주는 서비스**입니다. 소개팅을 직접 주최하지 않습니다. 지도·필터·요약 카드·상세 페이지·비교함까지의 탐색 경험은 MeetMap이 제공하고, **신청과 결제는 주최사의 기존 폼으로 리다이렉트**합니다.

## 주요 기능

### 사용자 기능

- 소셜 로그인 기반 회원가입 / 로그인
- 관심 지역, 성별, 출생연도 등 프로필 등록
- 소개팅 리스트 조회 및 비교
- 날짜, 지역, 가격, 연령대, 분위기 태그 기반 필터링
- 지도 기반 소개팅 조회
- 소개팅 상세 정보 확인
- 외부 신청 URL 이동 및 클릭 로그 추적
- 관심 소개팅 찜하기
- 참여 인증 기반 후기 작성
- 소개팅 / 후기 / 주최사 신고 기능
- 마이페이지 알림 기능

### 관리자 기능

- 관리자 로그인 및 권한 관리
- 주최사 관리
- 소개팅 등록 / 수정 / 삭제
- 태그 관리
- 후기 검수 및 블라인드 처리
- 소개팅 정보 오류 제보 관리
- 추천 소개팅 및 배너 관리
- 소개팅 조회수, 신청 클릭수, 찜 수, 후기 수 등 통계 관리

## 핵심 서비스 방향

MeetMap은 단순히 소개팅 정보를 나열하는 서비스가 아니라, 사용자가 소개팅 선택 전에 필요한 정보를 빠르게 비교할 수 있도록 설계합니다.

주요 차별점은 다음과 같습니다.

- 지도 기반 소개팅 탐색
- 카드형 소개팅 비교 UI
- 분위기 태그 기반 필터링
- 외부 신청 URL 클릭 추적
- 참여 이력 기반 후기 작성
- 관리자 검수를 통한 후기 신뢰도 관리
- 주최사별 소개팅 성과 통계 관리
