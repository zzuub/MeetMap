## P3-1 요점 — 끝났다 (2026-09-12, #31)

근거는 `decisions.md` **4.71** 하나에 모았다. 다음 판이 알아야 할 것만 적는다.

- **지도는 `bbox` 를 안 보낸다.** 마커 = 조건의 전건이고 조회는 서버(`page.tsx`)다. 뷰포트는 URL 에도 상태에도 없다 — 옮겨도 다시 조회하지 않는다
- **뷰포트는 결과가 정한다.** `planViewport` 가 전건을 담는 범위를 내고, 같은 결과를 다시 받으면 **사용자가 옮겨 둔 곳을 지킨다**. 그래서 `?district=` 로 들어와도 구 중심 좌표 없이 중심이 선다
- **마커는 있고 시트는 없다.** 지금 마커는 상세로 가는 링크다 — P3-2 가 시트로 바꿀 때 `features/event-apply` 를 경유한다 (4.38)
- **카카오 레벨은 작을수록 확대다.** `viewport.ts` 의 상수·판정이 전부 그 방향이고, 버튼 활성 판정과 실제 이동을 **모든 레벨에서 맞춰 보는 단언**이 있다 (P3-1 이 실제로 이걸로 방향 버그를 잡았다)
- **키는 `.env` 에 있어야 한다.** 없으면 `MAP_KEY_MISSING` 카드이고 test·build 는 통과한다 — 즉 **CI 는 지도를 못 본다**
