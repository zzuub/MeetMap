## 전제

기술 스택은 **Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4**, 폴더 구조는 [`src/README.md`](../../src/README.md)의 FSD 규칙을 따른다.

작성 원칙 두 가지가 사양 전체에 걸린다.

1. 목업에 **실제로 그려진** 요소만 기능으로 정의한다. 추정이 필요하면 `TBD` 로 두고 16장에 모은다.
2. 목업 우하단의 플로팅 탭바(`상세·신청 / 비교 / 찜`)는 **프로토타입 화면 전환용 장치**이며 제품 기능이 아니다. 실제 내비게이션은 하단 4탭(홈/지도/찜/마이) + 라우팅이다.

## 대상 목업 (claude.ai/design 캔버스)

리포지토리에 없다. 캔버스에서 연다.

| 파일 | 화면 |
| --- | --- |
| `MeetMap Onboarding.dc.html` | 로그인 / 약관 / 인트로 / 프로필 설정 / 완료 |
| `MeetMap User v2.dc.html` | 홈 / 탐색(리스트·지도) / 찜 / 마이 / 필터 시트 / 마커 시트 |
| `MeetMap Actions.dc.html` | 소개팅 상세 / 외부 신청 모달 / 비교함 / 찜 목록 |
| `MeetMap My.dc.html` | 알림함 / 알림 설정 / 후기 목록 / 후기 작성 / 마이페이지 |
| `MeetMap Support.dc.html` | 검색 / 위치 권한 / 빈 상태·에러 |

**목업이 없는 화면**: 주최사 소개 페이지 `/providers/[id]`, 주최사 후기 목록 (2026-09-02 신설 — 7.4). 이 문서가 원본이다.

⚠️ **목업(User v2 / Actions / My)은 아직 도메인 재정의 이전 기준이다.** 해당 화면 작업 전에 목업 갱신이 필요하고, 어긋나 보이면 이 사양이 원본이다 → [15-도메인-재정의-이력.md](15-도메인-재정의-이력.md).
