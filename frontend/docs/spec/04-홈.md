## 5. 홈 — `/`

### 5.1 구성 (상단 → 하단)

1. 앱 헤더 (로고 / 검색 / 알림)
2. 헤드라인 + 추천 기준 안내
3. 지도 프로모 카드
4. 섹션 A — 이번 주 인기 소개팅 (가로 스크롤)
5. 섹션 B — 내 나이대 소개팅 (가로 스크롤)
6. 섹션 C — 새로 등록된 소개팅 (세로 리스트)
7. 하단 내비게이션

> **퀵 필터 칩 바는 삭제됐다 (2026-09-01).** 홈에 필터를 두지 않는다. 근거는 5.4.

### 5.4 홈에 필터를 두지 않는다

**퀵 필터 칩 바(`오늘 / 점심 / 저녁 / 심야 / 3만원 이하`)를 삭제한다.** 홈의 필터 진입점은 없다.

| 근거 | 설명 |
| --- | --- |
| **칩이 필터처럼 생겼는데 링크로 동작했다** | 누르면 결과가 걸러질 것 같은데 실제로는 탐색 화면으로 이탈한다. 이 어긋남이 사용자가 체감한 문제의 정체다 |
| **필터는 한 군데만 있어야 한다** | 탐색 화면에 3층 구조 필터(6.4)가 이미 있다. 홈에 축이 겹치는 반쪽 필터를 두면 두 벌을 따로 유지해야 한다 — 2026-09-01 카테고리 축 개편에서 목업 10종을 전부 뒤진 비용이 그 실증이다 |
| **홈과 탐색은 역할이 다르다** | 홈은 큐레이션("우리가 골라 보여준다"), 탐색은 필터("네가 조건을 건다"). 칩은 탐색의 문법을 홈으로 끌고 들어온다 |
| **세로 공간** | 430px 화면에서 히어로 + 지도 카드 + 칩 줄 + 섹션 3개는 첫 화면에 카드가 안 들어온다 |
| **개인화는 고정 섹션이 담당한다** | `내 나이대 소개팅`(섹션 B)이 상설로 있으므로 칩으로 같은 걸 누를 이유가 없다 |

홈에서 화면을 떠나는 경로는 **`전체보기 >`(3개)와 지도 프로모 카드**뿐이다. 둘 다 이동한다는 사실이 라벨과 형태로 드러나므로, 칩처럼 기대를 배신하지 않는다.

> **되돌리기 조건.** 섹션이 5개 이상으로 늘어 홈이 스크롤 지옥이 되거나, 로그 분석에서 홈 → 탐색 이탈률이 지나치게 낮게 나오면 그때 재검토한다. 그 경우에도 칩을 되살리기보다 **섹션 자체를 개인화하는 방향**을 먼저 본다.
