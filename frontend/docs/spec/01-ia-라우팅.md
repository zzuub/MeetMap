## 1. 정보 구조(IA) 및 라우팅 맵

```
/onboarding                    온보딩 (로그인 → 약관 → 인트로 → 프로필 → 완료)
/onboarding/location           위치 권한 요청 / 지역 직접 선택

(main)                         하단 4탭 셸 (BottomNav 노출)
  /                            홈
  /explore                     탐색 (?view=list|map)
  /likes                       찜 목록
  /my                          마이페이지

/search                        검색 (전체화면, 탭바 없음)
/events/[eventId]              소개팅 상세
/providers/[providerId]        주최사 소개 페이지  ← 목업 없음 (7.4)
/providers/[providerId]/reviews 주최사 후기 목록   ← 목업은 My 의 후기 목록을 재사용 (10.4)
/compare                       비교함
/my/notifications              알림함
/my/notifications/settings     알림 설정
/my/reviews                    내가 쓴 후기
/reviews/write/[eventId]       후기 작성
/my/applications               신청 이력    ← 목업 없음, 진입점만 존재
/my/profile/edit               프로필 수정  ← 목업 없음, 진입점만 존재
/policy/terms                  약관 및 개인정보 ← 목업 없음, 진입점만 존재
```

### 1.1 라우트 그룹 설계

| 그룹 | 경로 | 설명 |
| --- | --- | --- |
| `app/(onboarding)/` | `/onboarding/*` | 하단 탭 없음. 전체화면 + 하단 시트 레이아웃 |
| `app/(main)/` | `/`, `/explore`, `/likes`, `/my` | `layout.tsx`에 `BottomNav` 고정 |
| `app/(stack)/` | `/events/[id]`, `/providers/[id]`, `/compare`, `/search`, `/my/**`, `/reviews/**` | 뒤로가기 헤더(`AppHeader`) 레이아웃, 하단 탭 없음 |

### 1.2 화면 전이도

```
[온보딩]
 로그인 ──소셜 인증──▶ 약관 ──필수동의──▶ 인트로 ──┬─"1분 만에 설정"─▶ 프로필 ─▶ 완료 ─▶ 위치권한 ─▶ 홈
                                                  └─"나중에 할래요"─────────────▶ 완료 ─▶ 위치권한 ─▶ 홈

[메인]
 홈 ──지도카드──────────▶ 탐색(map) ──마커──▶ 마커 시트 ──▶ 소개팅 상세
 홈 ──전체보기 > / 탐색탭─▶ 탐색(list) ──카드──▶ 소개팅 상세
                          탐색(list) ──뷰 토글──▶ 탐색(map)
 홈 ──검색 아이콘────────▶ 검색 ──결과 카드──▶ 소개팅 상세
 소개팅 상세 ──비교 담기──▶ 비교함 ──▶ 소개팅 상세
 소개팅 상세 ──신청하기──▶ 외부 이동 확인 모달 ──▶ (주최사 외부 페이지, 새 탭)
 소개팅 상세 ──주최사명──▶ 주최사 소개 페이지 ──┬─진행 중인 소개팅──▶ 소개팅 상세
                                              ├─후기 전체보기────▶ 주최사 후기 목록
                                              └─인스타 보기─────▶ (주최사 인스타, 새 탭)
 마이 ──▶ 알림함 / 알림 설정 / 내가 쓴 후기 / 후기 작성 / 찜 / 비교함
```

> **홈에는 퀵 필터 칩 바가 없다** (5.4). 홈에서 화면을 떠나는 경로는 `전체보기 >` 3개와 지도 프로모 카드뿐이다.
>
> **주최사 소개 페이지의 유일한 진입점은 소개팅 상세의 주최사명이다** (7.1). 카드에는 주최사 평점을 넣지 않으므로(7.4 근거) 목록에서 바로 들어가는 경로를 만들지 않는다.
