## 8. 비교함 — `/compare`

| 기능 | 사양 |
| --- | --- |
| 최대 담기 수 | **3개** |
| 헤더 | 타이틀 `비교함`, 액션 `전체 비우기` |
| 상단 안내 | `N개 소개팅을 비교하고 있어요` |
| 컬럼 헤더 | 소개팅별 썸네일 + 짧은 제목 + 우위 배지 + `빼기` |
| 비교표 행 | 참가비(내 성별 기준) / 일정 / 거리 / **주최사 평점** / 모집 상태 (5행 고정) |
| 우위 하이라이트 | 최저가·최단거리·최고평점 셀을 강조색 + 볼드 |
| 우위 배지 | `가성비`(최저가) / `가까움`(최단거리) / `후기 좋음`(**주최사 평점 최고**) — 소개팅당 1개, 우선순위 가성비 > 가까움 > 후기 좋음. **`가성비`는 사용자 성별 기준 가격으로 계산**한다 |
| 하단 안내 | `"거리는 현재 위치 기준이며, 평점은 해당 주최사가 진행한 소개팅의 후기를 모두 반영합니다"` |
| 하단 버튼 | `소개팅 상세로 돌아가기` |
| 그리드 | `84px + 1fr × N` (담긴 개수에 따라 컬럼 가변) |
| 빈 상태 | `"비교함이 비어 있어요 / 소개팅 상세에서 비교 담기를 누르면 최대 3개까지 나란히 볼 수 있어요"` + `소개팅 보러 가기` |

- 위치 권한 거부 시 `거리` 행 처리 — **TBD** (`-` 표기 권장)
- 가격 미확인(`null`) 건은 `가성비` 배지 후보에서 제외하고 `링크 확인`으로 표기한다. 게스트에게는 남·여 가격을 병기한다.
- **`주최사 평점` 행은 회차가 아니라 주최사의 값이다** (7.4). 같은 주최사의 회차를 둘 이상 담으면 이 행이 같은 값으로 나오고, 그때 `후기 좋음` 배지는 어느 쪽에도 붙지 않는다(동점).
- **후기 5건 미만인 주최사는 이 행에 `후기 N건`만 표기하고 `후기 좋음` 배지 후보에서 제외**한다. 가격 미확인 건을 `가성비` 후보에서 빼는 것과 같은 이유다 — 값이 없는데 우위를 주장할 수 없다.

## 9. 찜 목록 — `/likes`

| 기능 | 사양 |
| --- | --- |
| 헤더 | `내 찜 목록` / 액션 `편집` (일괄 삭제 모드 — 동작 **TBD**) |
| 안내 | `찜한 소개팅 N개` |
| 카드 | 썸네일 66px + 상태 배지 + 제목(1줄 말줄임) + `날짜 · 가격 · 거리` + 찜 해제 버튼 |
| 카드 클릭 | `/events/[id]` |
| 찜 해제 | 낙관적 업데이트로 즉시 제거. 되돌리기 제공 여부 **TBD** |
| 빈 상태 | `"아직 찜한 소개팅이 없어요 / 마음에 드는 소개팅의 동그라미를 누르면 여기에 저장돼요"` + `소개팅 탐색하러 가기` |
| 정렬 | 목업 미정의 — **개최일 가까운 순** 권장, **TBD** |

- 마감임박 알림은 삭제됐다(10.3). 신청 마감일이 존재하지 않아 발송 트리거를 만들 수 없다.
